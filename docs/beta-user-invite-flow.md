# Beta User Invite Flow

## 1. Prepare The Beta Cohort

- Start with a small group of trusted testers.
- Separate testers by role: student, teacher, parent, and school admin.
- Keep a private record of invited users and invite dates.

## 2. Send The Invite

Include:

- Abbot Study production or beta URL
- What the beta is for
- What features to try
- Known limitations
- Privacy policy link
- Terms link
- Beta feedback link
- Support contact

Suggested copy:

```text
You are invited to test Abbot Study, an AI-powered study platform that turns textbooks into ordered lessons with The Abbot and Ariel.

Please try:
- creating an account
- creating a subject
- uploading one PDF
- completing one lesson
- taking one concept check
- sharing feedback

This is a beta, so rough edges are expected. Your feedback will help shape the product before a wider launch.
```

## 3. Onboard In Small Batches

- Invite 5 to 10 users first.
- Wait for feedback and logs.
- Fix critical issues.
- Invite the next group only after the core flow is stable.

## 4. Monitor During Beta

Check daily:

- signup errors
- login/logout issues
- failed PDF processing
- parser warnings
- tutor failures
- MCQ generation failures
- admin audit logs
- feedback submissions

## 5. Close The Loop

- Thank testers.
- Tell them which issues were fixed.
- Ask for a second pass on fixed flows.
- Record product decisions from repeated feedback.
